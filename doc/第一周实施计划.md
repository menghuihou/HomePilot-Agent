## 3. 本周范围

### 本周要做

1. 启动本地依赖服务。
2. 建立 Alembic 迁移。
3. 建立 home、room、member、device、event 五类基础表。
4. 实现基础 CRUD。
5. 写入带 `synthetic` 标记的种子数据。
6. 实现 Streamlit 家庭状态页面。
7. 接入 OpenTelemetry 和 Langfuse。
8. 让第一次 LLM 调用生成 trace。

### 本周明确不做

- 不接入真实设备。
- 不实现 MCP Server。
- 不实现 LangGraph Agent。
- 不实现诊断子图。
- 不实现审批门控。
- 不实现巡检和日报。
- 不实现 RAG。
- 不实现长期记忆。
- 不做多用户权限。
- 不做生产部署。

## 8. 常见问题

| 问题 | 处理方式 |
| --- | --- |
| Docker Desktop 没启动 | 执行 `open -a Docker` 或 `docker desktop start` |
| PostgreSQL 未就绪 | 使用 healthcheck，等待 healthy 后再执行迁移 |
| Alembic 连接失败 | 检查 `DATABASE_URL_SYNC` |
| Streamlit 调 API 失败 | 检查 FastAPI 地址和 CORS |
| Langfuse 没有 trace | 检查 OTLP endpoint、service name、Langfuse key |
| 种子数据重复 | 使用唯一约束和幂等 upsert |
| API key 泄露风险 | 只放 `.env`，不写代码、日志或 trace |
